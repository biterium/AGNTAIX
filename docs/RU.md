# AIX : AGNTfi — кратко по-русски 🇷🇺

*(Полная версия на английском — [README.md](../README.md). Интерфейс симулятора переключается EN/RU мгновенно: [`sim/site/index.html`](../sim/site/index.html).)*

**AIX : AGNTfi** (бывший QuantumOrb) — терминал агентных финансов для Solana. 20 кошельков могут
принадлежать 4 людям — AIX AGNTfi показывает, кто на самом деле держит токен и что с этим делать.

## Шесть компонентов анализа запусков — от первой сделки до вердикта

1. **RADAR + SHIELD — раннее обнаружение.** RADAR в реальном времени следит за запусками pump.fun,
   прогрессом bonding-кривой, капитализацией и активностью торгов. SHIELD проверяет историю создателя
   и долю supply, выкупленную девом на старте. Движение $HOGE на 102.8x — пример того, почему важно
   поймать запуск рано: RADAR увидел токен на $17.9K капитализации, SHIELD прошёл проверки создателя,
   а рост до $1.84M дал бы 102.8x от этого снапшота.
2. **SCANNER — подозрительное распределение холдеров.** Изучает топ-20 держателей и первых 20 покупателей:
   историю торгов, время входа, переводы и остаток позиций. Fresh Wallet Ratio = 12/20 = 60% →
   Fresh Score = 25 × (0.80 − 0.60) / (0.80 − 0.10) = 7.1 / 25.
3. **CARTOGRAPHER — скрытые владельцы.** Связывает кошельки по прямым переводам, общему источнику токенов
   и покупкам в одной транзакции; доказанные связи объединяются в операторские группы, скоординированные
   пачки свежих кошельков получают пониженный вес, пока принадлежность не доказана.
4. **GUARD — накопление дева.** Проверяет запуски создателя, покупку в первом слоте и остаток на кошельке
   создателя. 320M из 1B supply в первом слоте = концентрация 32% → флаг до того, как запуск пройдёт
   проверки разработчика.
5. **ORB — модель стресса ликвидности.** Рост $KOOP на 8.7x в день запуска: сильной цены недостаточно.
   Impact(q, R) = 1 − (R / (R + q))²; доказанная группа кошельков, способная уронить цену на 50%+,
   даёт вердикт DANGER независимо от остальных компонентов.
6. **ORB — итоговая классификация риска.** Пять измерений риска складываются в счёт 0–100: влияние
   операторов, свежие кошельки, переведённый supply, невышедшие снайперы, доля топ-20 — с фиксированными
   кривыми штрафа, потолками счёта и жёсткими красными флагами.

Вердикты: **CLEAN · OK · RISKY · DANGER**. Правила открыты ([`rules/`](../rules)), пороги — в
[`rules/limits.js`](../rules/limits.js), каждое правило описано в [`docs/scoring.md`](scoring.md).

## Новое поколение: симулятор AGNTfi ([`sim/`](../sim))

- **WebSocket с реальными сделками** — живая лента Binance (публичный стрим); CoinGecko через WebSocket
  доступен только на платных планах, поэтому его ключ используется лишь для REST `/market_chart`.
- **Режимы рынка ТРЕНД / ФЛЭТ** по скользящей realized-волатильности — прямо под графиком Core Model.
- **Бумажный портфель** — сделки реально открываются и закрываются по TP / SL / горизонту, считается
  капитал. Ползунки TP / SL / горизонта пересчитывают симуляцию мгновенно.
- **Выбор монеты** — списком, кликом по бегущей строке или по карточке решения.
- **Экспорт решений в CSV**, пауза ленты, сброс портфеля.
- **Веер Монте-Карло p10–p90**, продолженный от 7-дневной цены на графике Core Model, плюс VaR 95%.

## Безопасность

Продукт никогда не просит приватные ключи, seed-фразы или средства. Ключи API живут только в переменных
окружения (`COINGECKO_API_KEY`) и никогда не попадают в репозиторий; засвеченный ключ немедленно
отзывается и перевыпускается — см. [SECURITY.md](../SECURITY.md). Неизвестное число остаётся N/A, никогда $0.
